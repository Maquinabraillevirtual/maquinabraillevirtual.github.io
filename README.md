# Máquina Braille Virtual

Escritura braille a seis teclas en el navegador: braille integral, estenografía y matemáticas,
con sonidos reales de una máquina Perkins, accesible con lectores de pantalla y línea braille.

Abrir la aplicación: https://maquinabraillevirtual.github.io

## Regleta Virtual

Regleta y punzón en pantalla, para aprender a formar las letras en espejo (de derecha a izquierda)
antes de pasar a la Máquina Braille Virtual. Los trabajos se guardan en braille Unicode (.txt) o BRF
para entregarlos al docente, que los abre en la misma Regleta para revisarlos.

Abrir la Regleta Virtual: https://maquinabraillevirtual.github.io/regleta/
